# 🚀 Express.js Multi-Feature Web App

A simple **Node.js + Express.js Web Application** that demonstrates multiple frontend features like **Login Page, Bulb Toggle, and Weather UI**.

This project is designed to showcase **server setup, routing, and static file handling using Express.js**.

---

## 📌 Project Overview

This application is a basic Express.js server that serves multiple HTML pages and demonstrates different functionalities.

It includes:
- Login interface  
- Bulb on/off UI interaction  
- Weather page UI  
- Static file serving  

---

## ✨ Features

- 🔐 Login Page UI  
- 💡 Bulb ON/OFF functionality  
- 🌦 Weather UI page  
- 🌐 Express server routing  
- 📂 Static file handling  
- ⚡ Lightweight and fast
